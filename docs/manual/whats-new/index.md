Each release's notes, as they were published with it. To update, run the installer again:

```sh
curl -fsSL https://raea.io/install | sh
raea --version
```

On Windows, in PowerShell: `irm https://raea.io/install.ps1 | iex`. The desktop app on the Mac updates itself; on
Windows and Linux, download the new version from [raea.io](https://raea.io). Each release says what is known to be
missing.
