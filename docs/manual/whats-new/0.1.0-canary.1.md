The first build of the raea engine you can install: `raea-motion`, the CLI that renders, plays and checks compositions written in React and TypeScript (`@raea/motion`), with the SDK, the lite runtime and the agent skills beside it.

```sh
curl -fsSL https://raea.io/install | sh
```

That installs into `~/.raea`, links `raea-motion` from `~/.local/bin`, and adds the `raea` and `raea-bevy` skills to `~/.claude/skills`, so a coding agent knows how to write and render with raea.

- macOS on Apple Silicon only.
- Canary: it changes daily, and parts of it are rough.
- Music and foley models (TokenSynth, SAO) install themselves the first time a composition asks for them.

### Web module (added 2026-11-06)
raea_shape_web.js and raea_shape_web_bg.wasm: this release's shapes (rdb/src/shape.rs: box, sphere, minus, hull, text3d with engine/fonts' bundled faces) compiled to wasm with the same mesh() as engine/shape-web, for @raea/r3f's loadShapes() (docs/r3f.feature R3F5). SHA256SUMS-web holds their hashes. Serve both files with your app (GitHub sends them as downloads, no CORS). This release has no raea-web module: engine/web came after it.
